# Dataset download instructions (MSD Task01_BrainTumour)

This repo expects the dataset extracted to:

data/Task01_BrainTumour/

Because download URLs may change, use the Medical Segmentation Decathlon page
and download **Task01_BrainTumour**.

After extraction, verify:
- dataset.json
- imagesTr/ and labelsTr/

Then run:
- python train.py
- python evaluate.py
